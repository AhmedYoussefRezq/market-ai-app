# Market AI — صفقة مدروسة بكل مفاتيح الذكاء الاصطناعي

تطبيق ويب للفون (PWA) بيحلل **السوق كله** ويطلع **صفقة مقترحة مدروسة**. بيستخدم كل مفاتيح AI اللي هتضيفها **في نفس الوقت**، وبيجمع رأي كل النماذج في قرار واحد.

> التطبيق **تحليل بس** — مفيش أي تنفيذ أوامر ولا ربط بأي حساب تداول.

## إيه اللي بيحصل في التحليل؟
1. **سحب بيانات مجانية**: أسعار OHLC من Yahoo Finance، سياق ماكرو (DXY، US10Y، VIX، S&P 500، Bitcoin، النفط)، وأخبار من Google News RSS.
2. **حساب المؤشرات**: EMA20/50، SMA200، RSI14، MACD، ATR14، Bollinger Bands، Stochastic، قمم/قواع 20 شمعة، اتجاه عام.
3. **إرسال كل البيانات لكل موديل** في طلب متوازي — كل مفتاح شغال في نفس اللحظة.
4. **تجميع الآراء**: أغلبية الاتجاه (BUY / SELL / WAIT)، وسيط الثقة والمستويات، وعرض رأي كل موديل على حدة.

## التشغيل
```bat
python app.py
```
أو `RUN_APP.bat`. التطبيق بيشتغل على البورت **8002**.

من الفون على نفس الـ Wi-Fi:
```
http://<IP-الكمبيوتر>:8002
```
للاستخدام من برة الـ Wi-Fi أو تثبيت PWA كامل، شغّل `PHONE_TUNNEL.bat` وافتح رابط `https://...` اللي هيطلع.

## إضافة مفاتيح AI
المفاتيح **مش موجودة في الريبو**، ولازم تضيفها أنت محلياً. الطريقتين:

**من التطبيق:** «إعداد مفاتيح AI» → الاسم + Base URL + الموديل + المفتاح → حفظ.

**من الكمبيوتر:**
```bat
python setup_keys.py
```
الإدخال مخفي (`getpass`) والمفتاح بيترح في `keys.local.json` فقط.

أمثلة لمزودين ليهم خطط مجانية (راجع الحد الحالي عند كل مزود):

| المزود | Base URL | موديل مثال |
|---|---|---|
| Groq | `https://api.groq.com/openai/v1` | `llama-3.3-70b-versatile` |
| OpenRouter | `https://openrouter.ai/api/v1` | `meta-llama/llama-3.3-70b-instruct:free` |
| Gemini | `https://generativelanguage.googleapis.com/v1beta/openai` | `gemini-2.0-flash` |
| Mistral | `https://api.mistral.ai/v1` | `mistral-small-latest` |
| Cerebras | `https://api.cerebras.ai/v1` | `llama-3.3-70b` |
| HuggingFace | `https://router.huggingface.co/v1` | `deepseek-ai/DeepSeek-R1-0528:free` |
| Together / DeepSeek / OpenAI / أي مزود متوافق | عرّفه بنفسك | — |

> كل مزود له حد مجاني مختلف. التطبيق هيستخدم كل المفاتيح المفعّلة في آن واحد في الوضع الافتراضي `ensemble`.

## الأدوات المتاحة
XAUUSD، XAGUSD، EURUSD، GBPUSD، USDJPY، BTCUSD، ETHUSD، US500، US30، NAS100، VIX، DXY، US10Y، WTI.

## الأوضاع
في `config.json`:
- `"mode": "ensemble"` — كل المفاتيح مع بعض (الافتراضي).
- `"mode": "failover"` — مفتاح بعد مفتاح لحد أول نجاح (أرخص وأسرع).

## التحليل التلقائي
اختر الأداة والفريم → «احفظ الإعداد للتحليل التلقائي» → «تشغيل التحليل التلقائي». بيشتغل كل 30 دقيقة (قابل للتعديل في `config.json`).

## الأمان
- المفاتيح في `keys.local.json` فقط ومستبعدة في `.gitignore`.
- الـ API محمي بتوكن محلي (`web_token.txt`) مدمج في الصفحة.
- أي استجابة أو log **ما بيحتويش على المفتاح**.
- متشاركش المفاتيح أو التوكن في أي محادثة.

## تحذير
الصفقة دي **رأي تحليلي** مش نصيحة مالية مضمونة. الأسعار والأخبار من مصادر مجانية عامة، وممكن تتأخر. راجع المستويات بنفسك قبل أي قرار.
